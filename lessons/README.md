# DelphiTeacher – Tananyag

A tananyag nem egyszerű referencia-dokumentáció. Minden modul célja, hogy egy fogalmat először megérts, utána saját kódban használd, végül valódi feladatban felismerd.

## Modulstruktúra

| Modul | Téma | Cél |
|---|---|---|
| 00 | Környezet és IDE | Delphi 13 magabiztos használata |
| 01 | Object Pascal alapok | Program szerkezete, változók, típusok, kifejezések |
| 02 | Vezérlési szerkezetek | Döntések és ciklusok |
| 03 | Procedures & Functions | Program felbontása és paraméterezés |
| 04 | Összetett adattípusok | array, dynamic array, record, enum, set |
| 05 | String, Date, Conversion | Gyakori üzleti adatok kezelése |
| 06 | Unitok és projektstruktúra | Több fájlból álló Delphi alkalmazás megértése |
| 07 | OOP | class, object, constructor, property, inheritance |
| 08 | Memória és ownership | objektumélettartam, try..finally, Free |
| 09 | Exceptions | hibák kontrollált kezelése |
| 10 | VCL alapok | Formok, komponensek, eventek |
| 11 | Collections & Generics | listák, dictionary-k, generikus típusok |
| 12 | Fájlkezelés | text, CSV, path, encoding |
| 13 | JSON és XML | strukturált adatcsere |
| 14 | SQL alapú alkalmazások | SQL és alkalmazáslogika szétválasztása |

| 17 | Legacy Delphi | meglévő vállalati kód olvasása |

## Egy modul belső felépítése

1. **Miért kell ezt tudni?** – valódi fejlesztési kontextus.
2. **Mentális modell** – hogyan gondolkodj a fogalomról.
3. **Szintaxis** – csak a szükséges Object Pascal nyelvi forma.
4. **Kis példák** – izolált működés.
5. **Gyakori hibák** – compiler/runtime/logikai hibák.
6. **Gyakorlat** – saját implementáció.
7. **Challenge** – kevesebb segítséggel megoldandó feladat.
8. **Munkahelyi kapcsolat** – hogyan jelenik meg valódi kódban.
9. **Checkpoint** – mit kell önállóan tudni a továbblépéshez.

## Haladási elv

Nem szükséges minden modult mereven sorrendben végigvinni. Ha egy valódi mini-projecthez előbb szükséges például FireDAC, akkor célzottan előrevesszük, majd később visszatérünk a hiányzó alapokhoz.

Ezért a curriculum két párhuzamos pályán működik:

**Foundation track** – szisztematikus Delphi tanulás.

**Work track** – szakmai vezetőtől kapott valódi feladatokhoz szükséges just-in-time tudás.

A két pálya egymást erősíti.
