# DelphiTeacher – Challenges

A challenge eltér a normál gyakorlattól.

A gyakorlat célja egy új fogalom megtanulása. A challenge célja annak ellenőrzése, hogy a már tanult fogalmat mennyi segítséggel tudod új helyzetben alkalmazni.

## Szabályok

1. A challenge elején nincs kész megoldás.
2. Először saját tervet készítesz.
3. Segítséget kérhetsz bármikor.
4. A mentor rögzíti, milyen segítségi szint kellett.
5. A hibázás nem sikertelenség; azt mérjük, hogy a hibából hogyan jutottál tovább.

## Értékelés

| Eredmény | Jelentés |
|---|---|
| Independent | önálló megoldás |
| L1 | iránymutatás kellett |
| L2 | konkrét hint kellett |
| L3 | kódváz kellett |
| L4 | közös implementáció kellett |
| L5 | mintamegoldásból kellett tanulni |

Az eredmény visszavezethető a `progress/competency-matrix.md` kompetenciáihoz.

## Challenge típusok

- **Syntax transfer** – ismert nyelvi elem új kontextusban.
- **Bug hunt** – hibás kód diagnosztizálása.
- **Code reading** – meglévő Delphi kód értelmezése.
- **Small feature** – kis funkció megtervezése és implementálása.
- **Refactor** – működő kód biztonságos javítása.
- **Data task** – fájl/adatbázis/adatfeldolgozási probléma.
- **Work simulation** – szakmai vezetőtől érkező feladathoz hasonló rövid specifikáció.

A későbbi challenge-ek egyre kevésbé lesznek tankönyvszerűek, és egyre jobban hasonlítanak valódi vállalati fejlesztési feladatokra.
